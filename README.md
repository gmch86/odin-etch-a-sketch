# Etch-a-Sketch - The Odin Project

An Etch-a-Sketch drawing app built as an assignment for The Odin Project using HTML, CSS and JavaScript.

## Features

- Customisable drawing grid
- Colour picker
- Rainbow mode
- Eraser
- Fill, lighten, darken and blend modes
- Undo and redo

[Live demo](https://gmch86.github.io/odin-etch-a-sketch/)
